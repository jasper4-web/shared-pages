The Claude Code toolkit

9 free add-ons from GitHub that turn Claude Code from a chat into a helper that actually does the work. Tap a name to see it on GitHub. Copy the line to install it.

Before you start

  1. You need Claude Code. Everything here plugs into it.

  3. Lines that start with / go in the Claude Code chat. Everything else goes in Terminal.

1

Chrome DevTools for agents

by Google’s Chrome team · ★ 58k

What it doesLets Claude drive your real Chrome: open pages, click, type, fill in forms, take screenshots and read what’s on the screen.

How it helpsHand Claude the boring web chores (setting up accounts, filling in listings, checking your site at phone size) and watch it do them in the Chrome you’re already signed into.

Get it · in Terminal
claude mcp add chrome-devtools --scope user -- npx -y chrome-devtools-mcp@latest --autoConnect --no-usage-statistics

Then in Chrome, open chrome://inspect/#remote-debugging, turn it on, and click Allow when Chrome asks. Start a new Claude Code chat. (“autoConnect” = use your own signed-in Chrome. “no-usage-statistics” = don’t send Google usage stats.)

Heads up: it can see and click anything in that Chrome, banking included. Watch it the first few times, and tell Claude: “ask me before you click Send, Post, Pay or Delete.”
Pairs well with: Claude in Chrome, Anthropic’s own Chrome extension (an official add-on, not on GitHub).

whisper.cpp

OpenAI’s Whisper, made to run on your own computer · ★ 55k

What it doesTurns any audio or video file into text, right on your computer. Free, works offline, and handles Spanish and many other languages.

How it helpsSend Claude a voice memo, a call recording or a video and it can actually read it: transcripts, captions, meeting notes.

Get it · in Terminal (Mac)
brew install whisper-cpp

Then tell Claude: “whisper is installed. Download a speech model for it and use it whenever I send you audio.” (One-time download.)

i-have-adhd

“No ADHD diagnosis needed!” · ★ 62k

What it doesStops Claude from burying the answer. The answer comes first, steps come numbered, and the “Hope this helps!” filler goes away.

How it helpsYou read the first line and you know what happened. Great if you skim, or talk to Claude by voice.

Get it · in Terminal
claude plugin marketplace add ayghri/i-have-adhd claude plugin install i-have-adhd@i-have-adhd

Then type /i-have-adhd in Claude Code.

4

attention-span

Ready-made talking styles · ★ 1.6k

What it doesGives Claude a standing “here’s how to talk to me” note (an output style) that applies to every chat, not just one.

How it helpsShort, skimmable, plain-English replies every time, without asking. Its “Attention-kind” style is a great starting point for building your own.

Get it · in the Claude Code chat
/plugin install attention-span --marketplace alexgreensh/attention-span

Then type /config → Output style → pick one.

5

Fixing Opus 5

One rules file · ★ 370

What it doesOne file of rules that cuts Claude’s verbal tics: the padding, the “you’re absolutely right”, the six headings for a one-line answer.

How it helpsTight, straight answers. It does only what you asked, never says “done” without evidence, and labels its questions (Q1, Q2) so you can answer by number.

Get it · in Terminal
curl -O https://raw.githubusercontent.com/disler/fixing-smartass-opus-5/main/sr_opus_5_system_prompt.md claude --append-system-prompt "$(cat sr_opus_5_system_prompt.md)"

The first line downloads the rules file; the second starts Claude with it. Or skip Terminal: ask Claude to copy the rules you like into your own settings.

6

Superpowers

The most-starred Claude add-on on GitHub · ★ 322k

What it doesA set of work habits for Claude: plan first, build in small steps, test as it goes, and check the result before it’s allowed to say “done”.

How it helpsFewer “it’s finished!” moments that turn out broken. Its “verification before completion” skill makes Claude prove the thing works.

Get it · in the Claude Code chat
/plugin install superpowers@claude-plugins-official

It’s in Anthropic’s official plugin store, so this one line is all it takes.

Answers as pictures · ★ 11k

Keep it safe

So you can let Claude work on its own without worrying.

8

cc-safety-net

A guard on every command · ★ 2.1k

What it doesChecks every command before Claude runs it, and blocks the ones that wipe folders, overwrite your saved work, or read your passwords and keys.

How it helpsMistakes get stopped before they happen. When it blocks something, it tells Claude why, so Claude picks a safer way on its own.

Get it · in Terminal (needs Node.js 22 or newer)
npx -y cc-safety-net@latest install npx -y cc-safety-net@latest doctor

The first line installs it. The second checks that it’s working.

Open on GitHub
9

Trail of Bits Claude Code setup

A security company’s own settings · ★ 2.1k

What it doesThe Claude Code setup a well-known security firm uses every day: blocks Claude from reading your keys and passwords, sets safer defaults, and adds good work habits.

How it helpsYou copy the pros’ safety settings instead of figuring them out yourself. It walks you through each piece and skips what you already have.

Get it · in Terminal
git clone https://github.com/trailofbits/claude-code-config.git cd claude-code-config claude

Then type /trailofbits:config in that chat and follow along.

Good to know

  • All 9 are free and open source. Stars (★) = how many people bookmarked it on GitHub.
  • Install from these links only. Copycat projects with similar names exist.
  • Add one at a time and use it for a day, so you know what changed.
  • Restart Claude Code (or start a new chat) after installing anything.
