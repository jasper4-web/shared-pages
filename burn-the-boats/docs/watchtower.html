Two traps this harness caught that a reading of the code would not:

  • localStorage.clear() in evaluateOnNewDocument runs on reload too, which fakes a persistence failure. Guard it with a sentinel key.
  • Changing tabs via go() is a hash navigation; puppeteer can detach the frame mid-evaluate. Load each screen fresh at index.html#/<tab> instead.
